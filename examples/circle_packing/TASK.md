# Goal

Improve `solve()` so that it returns eight points packed inside the unit square.

# Objective

Maximize the minimum Euclidean distance between every pair of points.

# Constraints

- `solve()` must return exactly eight `(x, y)` pairs.
- Every coordinate must be between `0.0` and `1.0`.
- Use only the Python standard library.
- The result must be deterministic.
